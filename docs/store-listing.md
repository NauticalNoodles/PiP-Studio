# Microsoft Store listing

Text for the Store listing in Partner Center, written so PiP Studio shows up when people search for
"picture in picture". Paste each part into the field it's named after. The Store version can't run as administrator
and has no phone companion, so the listing doesn't mention those.

## 1. App name

In **Product management > Manage app name reservations**, reserve:

```
PiP Studio - Picture in Picture
```

Then pick it as the **Product name** on the Store listing page. The name is what Store search weighs most. The app
itself still calls itself PiP Studio.

## 2. Search terms

Up to 7 terms of 30 characters or fewer, 21 words in all (these are 15):

```
picture in picture
pip
floating window
always on top
mini player
video over games
overlay
```

## 3. Short description

```
Picture-in-picture for any window on Windows: keep a video, stream or chat floating on top while you play or work.
```

## 4. Description

```
PiP Studio puts any window into picture-in-picture: a small floating window that stays on top of everything, so you can keep a video, a stream, a guide or a chat in view while you play a game or work.

Picture in picture for anything
• Any app's window, a whole display, or just a part of the screen
• Live and smooth, using Windows' own thumbnails, so it costs very little
• Also takes over the picture-in-picture windows of Chrome, Edge, Firefox, Discord and other apps

Made for gaming
• Floats over your games, and works in Windows' Xbox mode on handhelds and gaming PCs
• Use it entirely with an Xbox, PlayStation or Switch controller, with on-screen button hints
• Hides itself when you point at it, or slides out of the way

Neat and tidy
• Snaps to corners and edges, and PiPs stack and push each other aside instead of overlapping
• Save your PiPs as a layout and bring them all back in one go, or have them open when a game starts
• 8 sizes, opacity, volume and mute, crop and zoom, and theater mode for each PiP
• Keyboard shortcuts for everything

Light, dark and OLED themes, 9 languages, and screen reader support. Free and open source.
```

## Afterwards

- Listing changes can take a few days to show in Store search.
- Ratings count for a lot in search ranking. From 1.0.6, the Store version asks once for a rating, after a few days
  of use and a few PiPs, when you open its window. It never asks over a game.
- Links to the Store page from outside (the README, posts) help it show up in web searches.
